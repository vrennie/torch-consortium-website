# Editing the People directory

The four People page groups are defined in [data/people.json](data/people.json).
Move a person's filename slug between the `members` arrays to change their category.
Do not include the `.md` extension: `vincent-rennie` links to `content/pages/vincent-rennie.md`.
Order within a group is the order of its cards. Each card shows only the profile picture and title.

To change a displayed name or portrait, edit the person's file in `content/pages/`.
The first Markdown image in that file is used as the portrait.

**Important:** Initial current/past categories were compiled from historical Squarespace biographies, which do not reliably verify current employment or consortium membership. Review the four lists and move any profiles as needed. None of the underlying biographies were deleted.
